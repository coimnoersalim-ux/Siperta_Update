Import / Export Excel

Gunakan fitur ini untuk mengimpor data masal dari file Excel. Sistem otomatis menghapus teks "L=" atau "m2". Anda juga dapat mengekspor data yang sudah rapi ke format Excel (.xlsx) untuk laporan fisik desa.

Sistem Pindah Komputer (Backup JSON)

Data tersimpan aman di browser Anda saat ini. Jika ingin memindahkannya ke laptop lain:
1. Klik Backup Database (File .json terunduh).
2. Pindahkan file tersebut ke flashdisk.
3. Di komputer tujuan, klik Restore Database dan masukkan file tersebut.
