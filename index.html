Standarisasi Harga Tanah (Satuan Bata)

Tentukan harga per bata untuk tiap kategori tanah. Nilai tanah dihitung otomatis: Luas (m²) × 0,07 (faktor bata per m²) × harga per bata. Hasilnya tampil di tabel data, rekap, cetak F4, dan export Excel.

Pengaturan harga tersimpan di browser perangkat ini. Konversi: jumlah bata = luas (m²) × 0,07.

Import / Export Excel

Gunakan fitur ini untuk mengimpor data masal dari file Excel. Sistem otomatis menghapus teks "L=" atau "m2". Hasil export berupa file Excel (.xlsx) lengkap dengan kop desa, border, total, dan tanda tangan, sudah diatur untuk kertas F4 (Folio) sehingga langsung siap cetak.

Cetak Laporan F4 (per Blok atau Alamat Tanah)

Fitur khusus untuk mencetak rekap data bidang tanah berdasarkan lokasi/alamat tanah.
Sistem otomatis mengatur format kertas ke F4 (Folio) yang rapi, lengkap dengan kop surat dan area tanda tangan Kasipem.
